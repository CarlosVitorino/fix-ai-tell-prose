# fix AI-tell prose

Site owners and agencies pay a developer to crawl their sitemap, score each page for AI-sounding prose, and present human-approved fixes rather than auto-publish them.

- **Start here.** One SKILL.md (plus a small references/ folder) covering a first batch of the highest-confidence AI-tell patterns, each with detection criteria and a before→after replacement table, tested by running it against a handful of real pages and confirming a human reviewer would approve the rewrites. If it produces fixes you would actually sign off on, the crawl-and-score service wrapper can follow.
- **Stop if.** nothing!
