# Voice calibration

Removing tells is half the job. A rewrite that is free of tells but sounds like a different
company will be rejected. Calibrate once per site, before the first page, and put the
result in every review file as the voice note.

## 1. Find the owner's real voice

In order of preference:

1. A writing sample the owner gives you (emails to customers, a newsletter they wrote,
   notes from the founder).
2. The page on the site that sounds most like one person wrote it: often the About page,
   a founder's letter, an old blog post, or the FAQ.
3. If every page reads generic, the owner's description of how they talk to customers.
4. If you have nothing, use the defaults at the end of this file (or the SaaS preset for
   software sites) and say so in the voice note.

Never calibrate on the pages you are about to fix. Their voice is the problem.

## 2. Write the voice note

Five lines, each a fact you observed, not an adjective. Example:

```
Voice: first person plural ("we"), addresses reader as "you".
Sentences: mostly short (8–15 words); one longer sentence per paragraph.
Contractions: yes ("we're", "you'll").
Register: friendly trade, not corporate; uses "job" not "project".
House words: "the shop", "Saturday mornings", prices always in $ with no cents.
Source: About page (https://client.example/about), blocks b003–b009.
```

## 3. Apply it

- Use the same pronouns, contractions and register in every "after" passage.
- Prefer the house words over neutral synonyms.
- Match sentence length to the note, not to your default.
- Do not import personality the source does not have: no jokes, slang or exclamation marks
  unless the sample uses them.

## Defaults when there is no sample

For software, SaaS and AI-tool sites, use the preset in `references/voice-saas.md` instead
of the defaults below, and say so in the voice note.

Otherwise:

- "We" for the business, "you" for the reader.
- Contractions on (most small-business sites use them).
- Short to medium sentences; vary the length.
- Concrete nouns over abstractions; numbers as digits.
- No exclamation marks.

## By page type

| Page type | Lean towards | Watch for |
| --- | --- | --- |
| Home and service pages | Specific claims a customer can check: area served, hours, prices, turnaround | Cutting so much that the page loses its sales job; keep the call to action |
| About page | The owner's story in their words: dates, places, people | Inventing personal detail to replace empty praise; use owner questions |
| Blog posts | The writer's opinions, uncertainty and asides are welcome | Flattening a personal post into reference prose |
| Product and spec pages | Neutral, plain, exact | Touching specifications, prices or model names (protected) |
| Legal, policy, medical or financial pages | Leave as is; flag only as protected suggestions | Hedges that are compliance requirements |
